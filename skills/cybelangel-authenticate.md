# Authenticate to the CybelAngel APIs

Every CybelAngel API — Reports, Alerts, ADM Inventory, Keywords, Threat Intelligence,
Audit Logs, Partner — is protected by the same token. Do this once, then reuse it.

## Prerequisites

- `client_id` and `client_secret`, generated by a CybelAngel **platform admin** at
  Platform > Settings > CybelAngel API > "Enable API access" (or "Start 30-day trial").
- For the Alerts API only: a `stream_id`, issued by your Customer Success Manager. It is not
  self-serve; email support@cybelangel.com if you do not have one.
- For the Audit Logs and Partner APIs only: an `organization_id` (a UUID), also from your CSM.

## Steps

1. **Mint a token.** POST to `https://auth.cybelangel.com/oauth/token` with a JSON body:

   ```json
   {
     "client_id": "<client_id>",
     "client_secret": "<client_secret>",
     "audience": "https://platform.cybelangel.com/",
     "grant_type": "client_credentials"
   }
   ```

   The `audience` value is `https://platform.cybelangel.com/` **for every API**, including the
   ones served from `api.cybelangel.com`. Do not substitute the API host.

2. **Read `access_token` from the response.** It is an RS256 JWT. If you verify it, the keys are
   at `https://auth.cybelangel.com/.well-known/jwks.json`.

3. **CACHE IT.** This is not an optimization, it is a quota requirement: token minting is capped
   at **2,000 tokens per month per `client_id`**. A client that mints one token per API call
   exhausts a month of budget in under three hours at the documented 15 req/s ceiling. Store the
   token and reuse it until it expires.

4. **Assume a 1-hour lifetime.** The provider's docs disagree with themselves — the Reports and
   Audit Logs authentication pages say 1 hour, the Alerts "API calls" page says 24 hours, and the
   Reports OpenAPI carries `expires_in: 86400`. Treat 3600s as the ceiling, and refresh on any
   `401` rather than on a timer you trust.

5. **Send it on every request** as `Authorization: Bearer <access_token>`. Also send
   `Content-Type: application/json`.

## Rules

- Never put `client_secret` in a URL, query string, log line or support ticket — the docs call
  this out explicitly.
- There is no refresh token and no refresh flow. Re-run step 1.
- A `401` means the token is missing, malformed or expired → re-mint (once, then back off).
- A `403` means the token is valid but the grant lacks the scope or the organization right → do
  NOT re-mint, it will not help. On the Reports API check the scope set
  (`reports.read`, `reports.move`, `credentials.read`, `credentials.move`,
  `credentials.export`, `assets.download`, `usergroups.read`, `usergroups.admin`,
  `reports_global_comments.read`, `reports_global_comments.write`) against the operation.
- Self-throttle to **15 requests/second** and **20 in-flight requests**. There are no
  rate-limit response headers to read, and the docs do not say which status code you get when
  you exceed the ceiling.
